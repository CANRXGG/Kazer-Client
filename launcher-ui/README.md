# Kazer launcher UI source

This directory is a UI-only snapshot of the original Kazer launcher frontend.
It contains HTML, CSS and renderer interaction code, not the Minecraft client,
game modules, launcher backend, account vault, installer or binary releases.

The included original frontend source is covered by the accompanying MIT
license. This does not grant rights to Minecraft, CheatBreaker, Lunar Client,
OptiFine, donor cosmetics or other third-party code and artwork.

Image/font references in the source describe integration points. Proprietary
backgrounds, donor cosmetics and third-party artwork are intentionally excluded.
Use assets you have permission to distribute and a compatible host/preload API
when integrating this frontend. This snapshot alone is not a runnable launcher.

Release metadata is intentionally excluded: this source snapshot can contain
in-progress fixes and must not be treated as a verified client release.

The existing repository history, root documentation and license are preserved.
No Codeberg repository or full-client mirror is created by this export.
